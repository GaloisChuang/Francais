# Imparfait, futur simple, conditionnel et subjonctif

[← Retour à la table des matières](./la_table_des_matières.md)

這四組形式的關鍵差別是「時間」以及「說話者如何看待事件」。

| 形式 | 核心概念 | 中文提示 |
|---|---|---|
| imparfait | 過去的背景、狀態、習慣或進行中動作 | 當時正在……、以前常常…… |
| futur simple | 從現在看向未來 | 將會…… |
| conditionnel | 假設、願望、委婉或不確定 | 本來會……、如果……就會…… |
| subjonctif | 意願、情感、必要、判斷或懷疑 | 希望／必須／懷疑某人做…… |

## 1. L’imparfait

### 使用時機

- 描述過去的背景、天氣或狀態：*Il faisait froid.*
- 過去的習慣：*Quand j’étais petit, je lisais tous les soirs.*
- 過去正在進行、被另一事件打斷的動作：*Je dormais quand tu as appelé.*
- 兩件同時進行的過去動作：*Elle cuisinait pendant que je travaillais.*
- `si` 引導的現在或未來假設：*Si j’avais le temps, je voyagerais.*

### 變化規則

取現在式的 **nous** 形式，去掉 `-ons`，再加以下詞尾：

| 人稱 | 詞尾 | parler | finir |
|---|---|---|---|
| je | `-ais` | parlais | finissais |
| tu | `-ais` | parlais | finissais |
| il / elle / on | `-ait` | parlait | finissait |
| nous | `-ions` | parlions | finissions |
| vous | `-iez` | parliez | finissiez |
| ils / elles | `-aient` | parlaient | finissaient |

### 不規則形式

只有 **être** 使用特殊詞幹 `ét-`：

*j’étais, tu étais, il était, nous étions, vous étiez, ils étaient*

其他動詞即使現在式不規則，仍按照 `nous` 的形式建立詞幹：

- *nous avons → j’avais*
- *nous faisons → je faisais*
- *nous allons → j’allais*
- *nous prenons → je prenais*

### 與 passé composé 的差別

- imparfait：背景、狀態或進行中的動作，不強調起點和終點。
- passé composé：已完成、發生一次或推動故事的事件。

> *Il pleuvait quand Marie est arrivée.*  
> 當時正在下雨（背景），Marie 到達了（完成事件）。

[→ Voir la fiche détaillée sur l’imparfait](./l_imparfait.md)

## 2. Le futur simple

### 使用時機

- 未來事件或預測：*Demain, je travaillerai chez moi.*
- 承諾、命令或正式指示：*Je t’aiderai. Vous rendrez ce travail lundi.*
- `si + présent` 的結果：*Si tu viens, nous dînerons ensemble.*
- `quand, lorsque, dès que` 等未來時間子句：*Quand tu arriveras, appelle-moi.*

### 變化規則

- `-er`、`-ir` 動詞：完整不定式作為詞幹。
- `-re` 動詞：去掉最後的 `e`。
- 加上詞尾：**-ai, -as, -a, -ons, -ez, -ont**。

| 人稱 | parler | finir | prendre |
|---|---|---|---|
| je | parlerai | finirai | prendrai |
| tu | parleras | finiras | prendras |
| il / elle / on | parlera | finira | prendra |
| nous | parlerons | finirons | prendrons |
| vous | parlerez | finirez | prendrez |
| ils / elles | parleront | finiront | prendront |

### 常見不規則詞幹

| 動詞 | 詞幹 | 例子 |
|---|---|---|
| être | `ser-` | je serai |
| avoir | `aur-` | j’aurai |
| aller | `ir-` | j’irai |
| faire | `fer-` | je ferai |
| venir | `viendr-` | je viendrai |
| pouvoir | `pourr-` | je pourrai |
| vouloir | `voudr-` | je voudrai |
| devoir | `devr-` | je devrai |
| savoir | `saur-` | je saurai |
| voir | `verr-` | je verrai |
| envoyer | `enverr-` | j’enverrai |
| falloir | `faudr-` | il faudra |

> `si` 後面不用 futur simple：  
> ~~Si j’aurai le temps~~ → *Si j’ai le temps, je viendrai.*

[→ Voir la fiche détaillée sur le futur simple](./le_futur_simple.md)

## 3. Le conditionnel

### 3.1 Le conditionnel présent

#### 使用時機

- 假設的結果：*Si j’avais le temps, je voyagerais.*
- 願望：*J’aimerais vivre en France.*
- 委婉請求：*Pourriez-vous m’aider ?*
- 建議：*Tu devrais te reposer.*
- 未經證實的消息：*Le ministre serait malade.*
- 過去視角中的未來：*Elle a dit qu’elle viendrait.*

#### 變化規則

**futur simple 的詞幹 + imparfait 的詞尾**

| 人稱 | 詞尾 | parler | venir |
|---|---|---|---|
| je | `-ais` | parlerais | viendrais |
| tu | `-ais` | parlerais | viendrais |
| il / elle / on | `-ait` | parlerait | viendrait |
| nous | `-ions` | parlerions | viendrions |
| vous | `-iez` | parleriez | viendriez |
| ils / elles | `-aient` | parleraient | viendraient |

不規則詞幹與 futur simple 相同：`ser-`、`aur-`、`ir-`、`fer-`、`pourr-`、`voudr-` 等。

#### `si` 的搭配

**si + imparfait → conditionnel présent**

*Si j’avais une voiture, je partirais ce week-end.*

### 3.2 Le conditionnel passé

#### 使用時機

- 過去未實現的結果：*Si tu m’avais appelé, je serais venu.*
- 後悔：*J’aurais aimé rester.*
- 責備：*Tu aurais dû me prévenir.*
- 未經證實的過去消息：*Le ministre aurait quitté le pays.*

#### 變化規則

**avoir／être 的 conditionnel présent + participe passé**

- *j’aurais parlé*
- *elle serait venue*
- *nous aurions fait*

#### `si` 的搭配

**si + plus-que-parfait → conditionnel passé**

*Si j’avais étudié, j’aurais réussi.*

> `si` 後面通常不能直接使用 conditionnel：  
> ~~Si j’aurais su~~ → *Si j’avais su, je serais venu.*

[→ Voir le conditionnel présent](./le_conditionnel_présent.md) · [→ Voir le conditionnel passé](./le_conditionnel_passé.md)

## 4. Le subjonctif

Subjonctif 不是單純表示時間，而是表達說話者對事件的**主觀態度**。它通常出現在 `que` 引導的子句中。

### 4.1 Le subjonctif présent

#### 使用時機

| 類型 | 常見結構 | 例句 |
|---|---|---|
| 意願／命令 | vouloir que, demander que | *Je veux que tu viennes.* |
| 必要性 | il faut que, il est nécessaire que | *Il faut que nous partions.* |
| 情感 | être heureux que, regretter que | *Je suis heureux que tu sois ici.* |
| 懷疑／否定意見 | douter que, ne pas penser que | *Je doute qu’il sache.* |
| 判斷 | il est important que | *Il est important que vous lisiez.* |
| 連接詞 | pour que, bien que, avant que, sans que | *Bien qu’il soit tard, elle travaille.* |

肯定且表示確信的意見通常使用 indicatif：

- *Je pense qu’il vient.*
- *Je ne pense pas qu’il vienne.*

#### 變化規則

通常取現在式 **ils** 的形式，去掉 `-ent`，再加：

**-e, -es, -e, -ions, -iez, -ent**

| 人稱 | parler | finir | prendre |
|---|---|---|---|
| que je | parle | finisse | prenne |
| que tu | parles | finisses | prennes |
| qu’il / elle / on | parle | finisse | prenne |
| que nous | parlions | finissions | prenions |
| que vous | parliez | finissiez | preniez |
| qu’ils / elles | parlent | finissent | prennent |

`nous`、`vous` 經常使用現在式 `nous` 的詞幹，因此某些動詞有兩個詞幹：

- *que je vienne / que nous venions*
- *que je prenne / que nous prenions*
- *que je boive / que nous buvions*

#### 常見不規則形式

| 動詞 | je | nous | ils |
|---|---|---|---|
| être | sois | soyons | soient |
| avoir | aie | ayons | aient |
| aller | aille | allions | aillent |
| faire | fasse | fassions | fassent |
| pouvoir | puisse | puissions | puissent |
| savoir | sache | sachions | sachent |
| vouloir | veuille | voulions | veuillent |
| falloir | — | — | qu’il faille |

### 4.2 Le subjonctif passé

表示在主要動作之前已完成的行為：

**avoir／être 的 subjonctif présent + participe passé**

- *Je suis heureux que tu aies réussi.*
- *Je doute qu’elle soit partie.*
- *Bien qu’il ait beaucoup travaillé, il n’a pas terminé.*

比較：

- *Je veux qu’il vienne.*：希望他來，動作尚未完成。
- *Je suis heureux qu’il soit venu.*：他已經來了。

### 同主詞與不同主詞

- 同一主詞通常用 infinitif：*Je veux partir.*
- 不同主詞使用 `que + subjonctif`：*Je veux que tu partes.*

[→ Voir le subjonctif présent](./le_subjonctif_présent.md) · [→ Voir le subjonctif passé](./le_subjonctif_passé.md)

## 5. 快速選擇方式

1. 描述過去的背景、習慣或進行中動作？→ **imparfait**
2. 表示未來確定或預期會發生的事？→ **futur simple**
3. 表示假設、願望、委婉或不確定？→ **conditionnel**
4. 前面有意願、必要、情感、懷疑或特定連接詞？→ **subjonctif**

## 6. 必背公式

- **Imparfait**：`nous` 現在式去掉 `-ons` + `-ais, -ais, -ait, -ions, -iez, -aient`
- **Futur simple**：不定式詞幹 + `-ai, -as, -a, -ons, -ez, -ont`
- **Conditionnel présent**：futur 詞幹 + imparfait 詞尾
- **Si + présent → futur simple**
- **Si + imparfait → conditionnel présent**
- **Si + plus-que-parfait → conditionnel passé**
- **Subjonctif présent**：`ils` 現在式去掉 `-ent` + `-e, -es, -e, -ions, -iez, -ent`
