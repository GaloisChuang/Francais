# Le conditionnel passé

[← Retour à la table des matières](./la_table_des_matières.md)

## Emploi

- une conséquence irréelle dans le passé : *Si j’avais su, je serais venu.*
- un regret ou un reproche : *J’aurais aimé rester. Tu aurais dû me prévenir.*
- une action qui aurait pu se produire, mais ne s’est pas produite : *Nous aurions pu gagner.*
- une information passée non confirmée : *Le suspect aurait quitté le pays.*
- le futur antérieur vu depuis un moment passé : *Elle pensait qu’il aurait terminé avant midi.*

## Formation

**Auxiliaire `avoir` ou `être` au conditionnel présent + participe passé**

| Personne | parler | partir |
|---|---|---|
| j’ / je | aurais parlé | serais parti(e) |
| tu | aurais parlé | serais parti(e) |
| il / elle / on | aurait parlé | serait parti(e) |
| nous | aurions parlé | serions parti(e)s |
| vous | auriez parlé | seriez parti(e)(s) |
| ils / elles | auraient parlé | seraient partis / parties |

Le choix de l’auxiliaire et les accords suivent les règles du passé composé : *Elles seraient venues* ; *les erreurs qu’il aurait corrigées*.

## Formes irrégulières

Les auxiliaires utilisent les radicaux irréguliers `aur-` et `ser-`. Le verbe principal peut avoir un participe passé irrégulier.

| Infinitif | Participe passé | Exemple |
|---|---|---|
| avoir | eu | j’aurais eu |
| être | été | j’aurais été |
| faire | fait | elle aurait fait |
| devoir | dû | tu aurais dû |
| pouvoir | pu | nous aurions pu |
| vouloir | voulu | ils auraient voulu |
| prendre | pris | vous auriez pris |
| écrire | écrit | elle aurait écrit |
| venir | venu | ils seraient venus |

## Les phrases avec *si*

Pour une situation passée contraire aux faits :

**si + plus-que-parfait → conditionnel passé**

*Si tu m’avais appelé, je serais venu.*

La condition et la conséquence peuvent être mixtes : *Si j’avais accepté ce poste, j’habiterais aujourd’hui à Lyon.*

## La négation et les pronoms

La négation encadre l’auxiliaire : *Je n’aurais pas accepté.* Les pronoms se placent avant l’auxiliaire : *Je te l’aurais donné.*

## Exemples

- *Nous aurions aimé participer au projet.*
- *Vous auriez pu nous demander de l’aide.*
- *D’après le journal, ils se seraient rencontrés en secret.*
- *Si elle était partie plus tôt, elle n’aurait pas manqué le train.*

## Points à retenir

- Le conditionnel passé présente un résultat passé comme irréel, regretté ou incertain.
- **Si + plus-que-parfait** appelle généralement le conditionnel passé dans la conséquence.
- Ne pas écrire ~~*si j’aurais su*~~, mais *si j’avais su*.
- Vérifier le choix de l’auxiliaire et l’accord du participe passé.
