# Le conditionnel présent

[← Retour à la table des matières](./la_table_des_matières.md)

## Emploi

- une hypothèse ou sa conséquence : *Si j’avais plus de temps, je lirais davantage.*
- un souhait ou un désir : *J’aimerais vivre en France.*
- une demande, une suggestion ou un conseil atténué : *Pourriez-vous m’aider ? Tu devrais te reposer.*
- une information non confirmée, surtout dans la presse : *Le ministre annoncerait sa décision demain.*
- le futur vu depuis un moment passé : *Elle a dit qu’elle viendrait.*
- l’imaginaire ou le jeu : *Moi, je serais le médecin et toi, tu serais le patient.*

## Formation

**Radical du futur simple + terminaisons de l’imparfait**

Terminaisons : **-ais, -ais, -ait, -ions, -iez, -aient**.

| Personne | parler | finir | prendre |
|---|---|---|---|
| je | parlerais | finirais | prendrais |
| tu | parlerais | finirais | prendrais |
| il / elle / on | parlerait | finirait | prendrait |
| nous | parlerions | finirions | prendrions |
| vous | parleriez | finiriez | prendriez |
| ils / elles | parleraient | finiraient | prendraient |

Pour les verbes en `-re`, on enlève le `e` final : *prendre → je prendrais*.

## Radicaux irréguliers fréquents

Ils sont identiques à ceux du futur simple.

| Infinitif | Radical | Exemple avec *je* |
|---|---|---|
| être | ser- | je serais |
| avoir | aur- | j’aurais |
| aller | ir- | j’irais |
| faire | fer- | je ferais |
| venir | viendr- | je viendrais |
| tenir | tiendr- | je tiendrais |
| pouvoir | pourr- | je pourrais |
| vouloir | voudr- | je voudrais |
| devoir | devr- | je devrais |
| savoir | saur- | je saurais |
| voir | verr- | je verrais |
| envoyer | enverr- | j’enverrais |
| recevoir | recevr- | je recevrais |
| falloir | faudr- | il faudrait |

## Les phrases avec *si*

Pour une hypothèse présente ou future peu probable :

**si + imparfait → conditionnel présent**

*Si nous avions une voiture, nous partirions ce week-end.*

On ne met normalement jamais le conditionnel immédiatement après **si** : ~~*si j’aurais*~~ → *si j’avais*.

## La négation et les pronoms

La négation encadre le verbe : *Je ne ferais pas cela.* Les pronoms le précèdent : *Je vous le conseillerais.*

## Exemples

- *Je voudrais un café, s’il vous plaît.*
- *À ta place, j’accepterais cette proposition.*
- *Elle pensait que nous arriverions avant midi.*
- *Selon ce témoin, le conducteur serait déjà loin.*

## Points à retenir

- Radical du futur + terminaisons de l’imparfait.
- Le conditionnel atténue une demande et exprime la distance, l’hypothèse ou l’incertitude.
- **Si + imparfait** appelle généralement le conditionnel présent dans la conséquence.
- *Je voudrai* est un futur ; *je voudrais* est un conditionnel.
