# Le futur simple

[← Retour à la table des matières](./la_table_des_matières.md)

## Emploi

- une action ou un fait à venir : *Demain, je travaillerai chez moi.*
- une prévision ou une promesse : *Il fera beau. Je t’aiderai.*
- un ordre ou une consigne ferme : *Vous rendrez ce travail lundi.*
- une conséquence après **si + présent** : *Si tu viens, nous dînerons ensemble.*
- après certaines conjonctions temporelles, quand l’action est future : *Quand tu arriveras, appelle-moi.*
- une supposition concernant le présent, surtout avec *être* ou *avoir* : *Il ne répond pas ; il sera occupé.*

## Formation

On ajoute les terminaisons **-ai, -as, -a, -ons, -ez, -ont** au radical du futur.

- verbes en **-er** et **-ir** : infinitif complet + terminaison ;
- verbes en **-re** : infinitif sans le `e` final + terminaison.

| Personne | parler | finir | prendre |
|---|---|---|---|
| je | parlerai | finirai | prendrai |
| tu | parleras | finiras | prendras |
| il / elle / on | parlera | finira | prendra |
| nous | parlerons | finirons | prendrons |
| vous | parlerez | finirez | prendrez |
| ils / elles | parleront | finiront | prendront |

## Radicaux irréguliers fréquents

Les terminaisons restent régulières ; seul le radical change.

| Infinitif | Radical | Exemple avec *je* |
|---|---|---|
| être | ser- | je serai |
| avoir | aur- | j’aurai |
| aller | ir- | j’irai |
| faire | fer- | je ferai |
| venir | viendr- | je viendrai |
| tenir | tiendr- | je tiendrai |
| pouvoir | pourr- | je pourrai |
| vouloir | voudr- | je voudrai |
| devoir | devr- | je devrai |
| savoir | saur- | je saurai |
| voir | verr- | je verrai |
| envoyer | enverr- | j’enverrai |
| recevoir | recevr- | je recevrai |
| courir | courr- | je courrai |
| mourir | mourr- | je mourrai |
| falloir | faudr- | il faudra |
| pleuvoir | pleuvr- | il pleuvra |

## La négation et les pronoms

La négation encadre le verbe conjugué : *Je ne partirai pas.* Les pronoms se placent avant le verbe : *Je te le donnerai demain.*

## Exemples

- *Nous partirons dès que tout le monde sera prêt.*
- *Tu verras, tout ira bien.*
- *S’il pleut, nous resterons à la maison.*
- *Je ne pourrai pas venir ce soir.*

## Points à retenir

- Les terminaisons correspondent à celles du présent d’**avoir**.
- Les radicaux du futur simple servent aussi au conditionnel présent.
- Après **si**, employer le présent, pas le futur : *Si j’ai le temps, je viendrai.*
- Après *quand, lorsque, dès que* avec un sens futur, le français emploie normalement le futur.
