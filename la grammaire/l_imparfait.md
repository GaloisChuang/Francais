# L’imparfait

[← Retour à la table des matières](./la_table_des_matières.md)

## Emploi

- une description ou un état dans le passé : *La maison était silencieuse.*
- une habitude ou une répétition non délimitée : *Quand j’étais petit, je jouais dehors tous les jours.*
- une action en cours, sans insister sur son début ni sa fin : *Je lisais quand tu as appelé.*
- deux actions simultanées : *Pendant qu’elle cuisinait, je mettais la table.*
- une demande atténuée : *Je voulais vous poser une question.*
- une hypothèse après **si** : *Si j’avais le temps, je voyagerais davantage.*

## Formation

On prend la forme de **nous au présent**, on enlève `-ons`, puis on ajoute les terminaisons de l’imparfait.

Terminaisons : **-ais, -ais, -ait, -ions, -iez, -aient**.

Exemple — *parler* : `nous parlons` → radical `parl-`

| Personne | parler | finir | prendre |
|---|---|---|---|
| je | parlais | finissais | prenais |
| tu | parlais | finissais | prenais |
| il / elle / on | parlait | finissait | prenait |
| nous | parlions | finissions | prenions |
| vous | parliez | finissiez | preniez |
| ils / elles | parlaient | finissaient | prenaient |

## Le seul radical irrégulier

Le verbe **être** utilise le radical `ét-` :

| Personne | être |
|---|---|
| j’ | étais |
| tu | étais |
| il / elle / on | était |
| nous | étions |
| vous | étiez |
| ils / elles | étaient |

Tous les autres verbes suivent le radical de la forme de **nous** au présent, même s’ils sont irréguliers au présent : *nous avons → j’avais ; nous faisons → je faisais ; nous allons → j’allais*.

## Particularités orthographiques

- Les verbes en **-ger** gardent le `e` devant `a` : *je mangeais*, mais *nous mangions*.
- Les verbes en **-cer** prennent `ç` devant `a` : *je commençais*, mais *nous commencions*.
- Les verbes dont le radical se termine par `i` ont deux `i` à *nous* et *vous* : *nous étudiions, vous riiez*.

## Exemples

- *Il faisait froid et le vent soufflait.*
- *Chaque été, nous allions chez nos grands-parents.*
- *Je travaillais quand elle est entrée.*
- *Si vous habitiez plus près, nous nous verrions souvent.*

## Points à retenir

- L’imparfait décrit le contexte, la durée ou l’habitude ; il ne présente pas les limites de l’action.
- Son radical vient presque toujours de **nous au présent sans `-ons`**.
- Après **si** dans une hypothèse présente, on emploie l’imparfait, jamais le conditionnel.
- Dans un récit : imparfait = arrière-plan ; passé composé = événement achevé.
